Windows one-click shortcuts for ai_rf2
=======================================
Double-click any file here. Each one calls ..\demo_windows.bat with the right option.

0  SELF_TEST      checks the whole project on this laptop (silent, ~5 minutes)
1  LIVE_DEMO 1    plays radio programme 1 + live window (use this in the demo)
2  LIVE_DEMO 2    same with programme 2
3  your own file  drag any mp3 / wav / flac onto this file
4  microphone     live from the microphone or line-in
5  REPORT_DEMO    result table + timeline pictures (opens the pictures folder)
6  CLASSIFY       drag a file onto it: prints when speech starts / stops
7  RUN_TESTS      756 automatic tests
8  CHECK_SETUP    checks / installs missing Python packages (PyTorch is never touched)
9  LINUX (WSL)    runs the self-test in Ubuntu (WSL) on this laptop
10 WSL support    one time: adds sound + window support to Ubuntu (WSL)
11 CHOOSE AUDIO   opens a file window: pick any song / audio file on this laptop;
                  it plays through the speakers while the live window classifies it.
                  "Choose another file ..." in the window switches to the next song.

The first run of any of them may take a minute: it checks the Python packages once.
